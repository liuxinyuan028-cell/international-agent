# 特稿工序卡（体裁：特稿 feature）

**何时用**：深度 / 特稿 / longform（长文）。  
**不用**：短帖 5W、通稿电头、短视频分镜。  
**细则**：`china-story-feature-reference.md`（南周方法）。铁律：`intl-comm.md`（国际传播）+ evidence（证据规则）。  
**状态**：`methods_in`（方法已入库、评测未齐）。**禁止复述教材范文原文。**

## 步骤

1. 动笔前能答：为何写、为何现在、五维度、**一句话主心骨**；答不出 → 停或填 `missing_fields`（缺失字段）
2. 结构：开头可感场景/具体问题 → 情节与冲突（材料支撑）→ 收束回味（禁帖文式 CTA 行动号召）
3. 场景细节 100% 可核验；无材料不编现场/对话/钟点
4. 输出字段见下；可标 `genre_status: methods_in`（体裁状态：方法已入库）

## 输出字段

必填：`genre: feature`（体裁：特稿）· `headline`（标题）· `dek`（副题/导语摘要）· `body`（正文）· `one_liner`（一句话主心骨）· `five_dimensions`（五维度）· `evidence_used`（已用证据）  
可选：`pull_quote`（提引句）· `suggested_visuals[]`（建议配图列表）· `missing_fields`（缺失字段）  
不要：`five_w`（帖文 5W）/ hashtag（话题标签）堆 / emoji（表情）作主成品

## 红线

- AI 不能补采访；宁短宁停  
- 禁通稿腔开篇、禁 IG（Instagram）钩子收束、禁抽象空话停在「正确中部」  
- 南周方法只用结构规则，不抄范文
