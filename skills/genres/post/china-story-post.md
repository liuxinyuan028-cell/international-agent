# 帖文工序卡（体裁：帖文 post）

**何时用**：海外社交帖 / thread（长帖串）/ 图文 caption（配文）。  
**不用**：通稿、特稿、短视频分镜、FAQ（常见问答）清单。  
**细则**：`china-story-post-reference.md`（勿整篇注入）。铁律：`intl-comm.md`（国际传播）+ evidence（证据规则）。

## 步骤

1. 确认 platform（平台）/ country（目标国）/ identity（发声身份）；缺省：instagram（图片社交）/ America（美国）/ online_influencer（网络博主）
2. 写实 `five_w`（5W 要素，不可空壳）；正文必须能对照回 5W
3. 正文骨架：钩子场景 → 1 个感官/地点锚 → 1 个 evidence（证据）事实 → 轻收束/提问
4. 按 format（成品形态）填字段（见下）；攻略数字放 `ops_tips`（运营提示），不进故事主句
5. 自检：无空壳诗句、无猎奇刻板、无抬杠、数字可追溯 evidence（证据）

## 输出字段

| format（成品形态） | 主字段（括号内为中文） |
|--------------------|------------------------|
| `social_post` 单帖（默认） | `post`（正文）+ `five_w`（5W）+ `hashtags`（话题标签）+ `platform`（平台）；可选 `alt_versions`（备选稿）/ `ops_tips`（运营提示） |
| `thread` 长帖串 | `tweets[]`/`posts[]`（各条正文）+ `five_w` + `hook`（钩子）/`cta`（行动号召） |
| `visual_story` 图文轮播 | `slides[]`（各页）+ `cover_line`（封面句）/`cta`（行动号召） |
| `caption_only` 仅配文 | `caption`（配文）+ hashtags（话题标签）/ `alt_text`（无障碍说明文字）/`cta` |

## 5W 一句话标准

| W（要素） | 中文 | 必须能回答 |
|-----------|------|------------|
| Who | 谁在说 | 发声角色与语气一致 |
| Says What | 说什么 | 一句可核验主点（有场景锚） |
| Channel | 通过什么渠道 | 平台长度与口吻匹配 |
| To Whom | 对谁说 | 至少一句当地可感 |
| Effect | 期望什么效果 | 可分享收束，非空赞口号 |

## 红线

- 证据没有的职务/金额/人次等 → 删  
- 禁：Culture speaks quietly（文化静静诉说）式空壳；饮食猎奇刻板；通稿腔；踩他国  
- 单帖只留 **一个** Says What（说什么）
